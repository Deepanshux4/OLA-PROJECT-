# 🚖 OLA Ride Booking Analytics Dashboard

> An Interactive Business Intelligence Dashboard built using **Power BI** and **SQL** to analyze over **100,000 ride booking records** and generate valuable business insights.

---

## 📌 Project Overview

This project provides a complete analysis of OLA ride booking operations by transforming raw ride booking data into an interactive Power BI dashboard.

The dashboard helps monitor:

- 📈 Booking Performance
- 💰 Revenue Analysis
- 🚕 Vehicle-wise Performance
- ❌ Cancellation Insights
- ⭐ Customer & Driver Ratings

The project combines **SQL** for data analysis and **Power BI** for visualization, creating a real-world Business Intelligence solution.
