# 📌 Project Overview

The **OLA Ride Booking Analytics Dashboard** is a Business Intelligence project that transforms raw ride booking data into an interactive reporting solution using **SQL** and **Power BI**.

The project focuses on analyzing ride bookings, revenue, cancellations, payment methods, customer behavior, vehicle performance, and ratings through dynamic visualizations.

Using SQL, the raw dataset was explored and analyzed before importing it into Power BI, where data modeling, DAX measures, KPIs, and interactive dashboards were developed.

The dashboard contains **5 fully interactive report pages** connected through **Page Navigation Buttons**, allowing users to move seamlessly between different analytical views. Filters, slicers, and cross-highlighting make the dashboard highly interactive and user-friendly.
